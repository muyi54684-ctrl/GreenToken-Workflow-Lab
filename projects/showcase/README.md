# GreenToken · AI Workflow Lab

一个独立、零依赖的本地项目展示页。使用已经保存的真实实验结果，展示策略控制、资源观测与分镜内容审计。

## 打开

直接双击 `index.html` 即可使用。推荐在本目录执行 `node serve.mjs` 后打开 http://127.0.0.1:4178 。按 Ctrl+C 停止本地服务。

页面不调用 API、不读取环境变量、不需要 Key、不安装依赖。数据、字体、脚本均在本机；没有外部 CDN、分析统计或远程请求。页面 CSP 禁止 connect-src。

## 演示方式

点击“播放项目演示”，约 72 秒自动依次介绍：实验总览 → Baseline → low → Baseline 内容变化 → low 内容变化 → Skip → 调用追踪 → 观察模式。可暂停、前进、后退，Esc 结束。它是历史记录讲解，不模拟真实请求进度。

手动探索：切换三种策略；对照原始 D 与 R/F；展开分镜原文、七维评分；切换请求参数、usage、快照哈希；导出当前脱敏记录；查看五类离线观察案例。

## 展示边界

- 只有一个冻结剧本案例，两次成功真实 Review，另有一次旧超时尝试。不是随机配对或大样本验证。
- Baseline 未显式设置 reasoning_effort，不能称为 High；low 只新增 reasoning_effort=low。
- Skip 是人工指定的离线 Final 对照，不是自动判断成功跳过。没有调用的增量资源为零，模型响应字段为 null。
- 费用使用冻结价格表作统一参考，不是实际账单；两组缓存和时间条件不同。
- 分镜画面为手绘 SVG 示意，不是生成的视频帧。中文描述为便于展示的概述，“记录原文”来自历史快照。
- 七维分数是 AI 文本审阅建议，非正式人工评分；三种结果都没有被判为质量合格。
- 观察模式不会改变 Review 路径。29 个挑战案例中，2 个误批准输入被错误地建议跳过，已明确展示。

## 文件

- index.html / style.css / app.js：界面、响应式布局和历史数据交互。
- data.js / evidence.json：从历史记录按字段白名单导出的相同数据集。无密钥、个人本机路径、完整模型请求或模型推理正文。
- mark.svg：项目标识。
- serve.mjs：只监听 127.0.0.1 的本地预览，只允许读取展示文件，不暴露工作区。

在集成工作区运行 `python -X utf8 -B tools/export-showcase.py` 可重建展示数据；此命令依赖本机私有实验目录，会先核验记录和 D/R/F 哈希。展示本身无需这些私有目录。
